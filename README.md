# Exam Study Hub

A static study website for middle-exam material. It uses only HTML, CSS and JavaScript, so it can be hosted free with GitHub Pages.

## Test locally in VS Code

1. Open the `middle-exams` folder in VS Code.
2. Install the **Live Server** extension by Ritwick Dey if you do not already have it.
3. Open `index.html`.
4. Right-click in the editor and choose **Open with Live Server**.
5. Test every subject and document button.

## Publish free with GitHub Pages

1. Create a free GitHub account if needed.
2. Create a **new public repository**, for example `middle-exams`.
3. Upload **the contents of this folder** so `index.html` is at the repository root.
4. Open the repository on GitHub → **Settings** → **Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch **main** and folder **/(root)**, then click **Save**.
7. Wait a minute or two. GitHub will show the public website URL on the Pages screen.

Important: filenames and links are case-sensitive on GitHub Pages. The files in this version have been normalized for that reason.
